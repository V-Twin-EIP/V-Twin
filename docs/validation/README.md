# Sandbox validation

The first validation campaign concerns friction and lubrication at the top compression ring–liner contact in the selected Ricardo Hydra case. Liner sliding wear is the later quantitative target. Validation of a live vehicle twin is outside this campaign.

The campaign will compare nominal, high-load, transient, cooling-degradation, viscosity-weakness, and corrective cases. It must establish which observables can distinguish the configurations, with reproducible inputs and justified uncertainties and tolerances.

All six scenarios are planned. The current code provides generic numerical integration checks; it does not yet implement the contact, lubrication, thermal, or wear models needed to execute them.
